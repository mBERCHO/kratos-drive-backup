Kratos Drive Backup

Kratos Drive Backup é um componente privado do sistema Kratos, utilizado para organizar e proteger arquivos de produções audiovisuais.

Com autorização do usuário, o aplicativo utiliza a API oficial do Google Drive para enviar, verificar e restaurar arquivos de backup.

O acesso é concedido através do Google OAuth 2.0. O aplicativo não é disponibilizado publicamente para instalação.
